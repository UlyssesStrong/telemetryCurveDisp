# telemetryCurveDisp

遥测数据曲线显示工具，用于可视化展示实时或历史遥测数据。

## 简介

本项目提供一套遥测数据曲线显示解决方案，适用于航天、航空、工业控制等领域的遥测数据可视化分析。支持多通道数据同步显示、实时刷新与历史回放。

## 功能特性

- 多通道遥测曲线同步显示
- 实时数据流接入与动态刷新
- 历史数据回放与对比分析
- 支持缩放、平移等交互操作
- 可配置的量程与告警阈值
